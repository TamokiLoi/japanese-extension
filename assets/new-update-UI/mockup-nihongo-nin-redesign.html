Definition of Done

  • ✓Mobile content-first — card đầu tiên nằm trong viewport ban đầu
  • ✓Filter mặc định ẩn, mở qua Filter Sheet
  • ✓Active filters hiển thị dạng chip nhỏ, không chiếm nhiều hàng
  • ✓Sort/Random gọn trong toolbar 3 nút
  • ✓Luyện đọc mobile chuyển sang list có đủ title/nguồn/độ dài/trạng thái
  • ✓Desktop dùng sidebar + filter cố định, không cần sheet
  • ✓Không đổi route, không đổi filter/data hiện có

Không được làm chỉ vì redesign

  • Xóa filter hoặc data hiện tại
  • Đổi schema, API contract, route
  • Đổi logic SRS/review, cách tính progress, quiz scoring
  • Rewrite toàn bộ kiến trúc khi chỉ cần refactor UI

Cách đọc mockup này: mọi filter/chip/dropdown hiện có trong app thật đều được giữ nguyên nhãn và số liệu, chỉ đổi vị trí hiển thị (toolbar gọn + Filter Sheet / sidebar). Bottom nav dùng nhãn tiếng Anh ngắn (Home/Voca/Bunpo/Quiz/More) để tiết kiệm chiều ngang; tiêu đề màn và nội dung học vẫn giữ tiếng Việt như hiện tại. Vocab là màn duy nhất demo tương tác mở/đóng sheet.
