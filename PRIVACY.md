# Privacy Policy — Nihongo Nin

Last updated: 2026-08-21

Nihongo Nin is a Japanese-learning browser extension. This policy explains what data it does — and does not — handle.

## Data collection

Nihongo Nin does **not** collect, transmit, sell, or share any user data. It does not use analytics, does not make network requests, and does not have a backend server.

## Local storage

The extension stores the following on your own device only, using the browser's built-in `chrome.storage.local` API:

- Which JLPT levels you've selected to study
- Whether random-order mode is on, and its shuffle seed
- Your current position in the Kanji list
- Reminder notification settings (enabled/disabled, interval)

This data never leaves your device and is not accessible to the developer or any third party.

## Permissions

- **storage** — to save the settings above locally.
- **alarms** — to schedule periodic review-reminder notifications.
- **notifications** — to show those reminders as system notifications.

None of these permissions are used to access, read, or transmit data from the websites you visit.

## Bundled content

The extension bundles a static Kanji dataset (readings, meanings, radicals) built from open sources (KANJIDIC2, Unihan, CC-CEDICT) plus supplementary Vietnamese meanings/mnemonics. This dataset ships with the extension package and is not fetched from any server at runtime.
