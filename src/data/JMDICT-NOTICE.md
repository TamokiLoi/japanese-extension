# JMdict data attribution

`vocab-reading-variants-jmdict.json` contains selected JMdict readings and English glosses, paired with concise Vietnamese translations prepared for this app. The source dictionary is distributed through [scriptin/jmdict-simplified, release 3.6.2+20260817122448](https://github.com/scriptin/jmdict-simplified/releases/tag/3.6.2%2B20260817122448).

The selected dictionary-derived fields and their translations in the JSON file are provided under the same license. JMdict-derived English glosses appear in the interface with a source label; the complete attribution is provided here.
